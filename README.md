# 台股智慧篩選雷達 Stock Radar

Python + Flask 的台股篩選 WebUI。預設載入 **20 支熱門股票**，可自由新增／刪除，
對每一檔做 **五大構面量化評分**，依總分由高至低排序，點任一列會在**右側面板**即時顯示
個股詳細資料與 **K 線圖**，清單不會重新載入。

所有數字皆為**真實市場資料**，透過 API 即時取得，沒有任何模擬或寫死的行情。

---

## 快速開始

```bash
pip install -r requirements.txt
python app.py
```

啟動後會自動開啟瀏覽器指向 <http://127.0.0.1:5000>。
Windows 也可以直接雙擊 `run.bat`。

## 資料來源（全部為真實 API）

| 資料 | 來源 |
|------|------|
| 日 K 線（開高低收量，最長 2 年） | Yahoo Finance（`yfinance`，代碼 `2330.TW` / 上櫃 `.TWO`） |
| 基本面：本益比、股價淨值比、殖利率、ROE、市值、營收年增率 | Yahoo Finance |
| 全市場代碼與中文名稱（上市） | 臺灣證券交易所 TWSE OpenAPI `STOCK_DAY_ALL` |
| 全市場代碼與中文名稱（上櫃） | 櫃買中心 TPEx OpenAPI `tpex_mainboard_daily_close_quotes` |

資料皆有記憶體 TTL 快取（K 線 15 分鐘、基本面 60 分鐘、名稱表 12 小時），
按右上角「重新整理」會清掉快取重抓。20 檔以 6 條執行緒並行抓取。

## 評分規則（滿分 100）

| 構面 | 配分 | 看什麼 |
|------|------|--------|
| **趨勢結構** | 30 | 股價對 MA20 / MA60 乖離、MA5 與 MA20 發散程度、月線一個月的斜率 |
| **動能表現** | 25 | RSI(14)（55–70 最佳、>80 過熱扣分）、MACD 柱狀是否翻正並擴大、近 20 日報酬 |
| **量能結構** | 15 | 5 日均量 / 20 日均量（1–2 倍為健康放量）、量價配合（漲要有量、跌要量縮） |
| **風險控制** | 15 | ATR 日均波動度、近 60 日最大回撤（波動與回撤越小分數越高） |
| **價值評估** | 15 | 本益比、股價淨值比、現金殖利率 |

分級門檻：

| 總分 | 評等 | 標籤 |
|------|------|------|
| ≥ 82 | A+ | 極強 |
| ≥ 74 | A | 強勢 |
| ≥ 66 | B+ | 偏多 |
| ≥ 58 | B | 中性偏多 |
| ≥ 50 | C+ | 中性 |
| ≥ 42 | C | 偏弱 |
| < 42 | D | 弱勢 |

每個構面在個股詳細頁都會列出**得分理由**（例如「站上月線 +5.4%」「MACD 紅柱擴大」），
評分是可被檢驗的，不是黑箱。權重與門檻都可在 `config.py` 調整。

## 功能

**觀察清單首頁**
- 預設 20 檔熱門股，依綜合評分排序；也可改以漲跌幅、趨勢、價值、代碼排序
- 每列顯示收盤、漲跌、漲跌幅、成交量、5/20 日報酬、RSI、月線乖離、五構面迷你長條、總分、評等
- 上方輸入框支援**代碼或中文名稱**即時搜尋全市場（含上櫃，已排除權證），↑↓ 選取、Enter 加入
- ✕ 移除個股；「回復預設 20 檔」可還原
- 清單存在 `watchlist.json`，關掉程式再開仍在

**個股明細面板**（點任一列在右側展開）

面板開啟後清單仍在原地，切換個股只會請求該檔資料，不會重抓整份觀察清單。
操作：↑ ↓ 切換上下一檔、`Esc` 關閉、⤢ 另開獨立視窗（`/stock/<code>` 仍可單獨使用）。

- K 線圖：日 K＋MA5/20/60＋布林通道，下方三格為成交量、MACD、KD，可框選縮放
- 期間切換 3 月 / 6 月 / 1 年 / 2 年
- 評分拆解（含各構面得分理由）、技術指標、基本面、近 10 個交易日明細

漲跌配色採台股慣例：**紅漲綠跌**。

## 專案結構

```
app.py           Flask 路由與 API
config.py        預設 20 檔清單、快取秒數、評分權重與分級門檻
data_source.py   Yahoo Finance / TWSE / TPEx 取數與快取
indicators.py    MA、RSI、MACD、KD、布林、ATR、最大回撤
rating.py        五大構面評分引擎
store.py         watchlist.json 讀寫
templates/       index.html（清單＋右側明細面板）、detail.html（個股獨立頁）
static/          style.css、app.js、detail-view.js（明細渲染，兩處共用）、
                 detail.js、echarts.min.js（已內建，離線可用）
```

## API

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/watchlist` | 取得清單並完成評分排序，`?refresh=1` 強制重抓 |
| POST | `/api/watchlist` | `{"code":"2330"}` 新增 |
| DELETE | `/api/watchlist/<code>` | 移除 |
| POST | `/api/watchlist/reset` | 回復預設 20 檔 |
| GET | `/api/search?q=` | 全市場代碼／名稱搜尋 |
| GET | `/api/stock/<code>?period=1y` | 個股 K 線序列＋指標＋基本面＋評分 |

## ☁️ 部署到 Render

本專案是 Flask 伺服器應用，需要 Python 執行環境。
**Netlify / GitHub Pages 這類純靜態平台無法運行**，請使用 Render（或 Railway、Fly.io 等支援 Python 的平台）。

repo 根目錄已附 `render.yaml`，步驟：

1. 到 [dashboard.render.com](https://dashboard.render.com) 用 GitHub 帳號登入
2. **New → Blueprint** → 選擇 `Stock-Radar-API` 這個 repo
3. Render 會自動讀取 `render.yaml`，按 **Apply** 即開始建置
4. 完成後取得網址 `https://stock-radar-xxxx.onrender.com`

之後推送到 `main` 分支會自動重新部署。

### 線上版的已知限制

| 項目 | 說明 |
|------|------|
| 冷啟動 | 免費方案閒置 15 分鐘會休眠，下次開啟需等約 50 秒喚醒 |
| 觀察清單 | 存在容器本機檔案，**重新部署或休眠重啟後會重置回預設 20 檔** |
| 記憶體 | 免費方案 512MB，pandas/numpy 佔用較高，故設定為單一 worker |
| 首次載入 | 一次並行抓 20 支股票行情，約需 10～30 秒 |

若要讓觀察清單永久保存，需將 `store.py` 改接雲端資料庫（如 Supabase / Postgres）。
